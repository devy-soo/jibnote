# 집노트 (Jibnote)

전세·월세 매물을 손품 파면서 사진과 정보를 저장해두는 개인용 웹앱입니다.
`화면예시/집로그 프로토타입.dc.html` 목업을 기반으로 실제 동작하는 앱으로 구현했습니다.

PC와 휴대폰 등 여러 기기에서 같은 계정으로 로그인하면 매물이 동기화됩니다.

## 실행 방법

서버와 클라이언트를 각각 켜야 합니다 (터미널 2개 필요).

```bash
# 1) 서버 (최초 1회만 prisma:migrate 필요)
cd server
npm install
npm run prisma:migrate   # 최초 1회 — SQLite DB 생성
npm run dev               # http://localhost:4001

# 2) 클라이언트 (새 터미널)
npm install
npm run dev               # http://localhost:5173
```

브라우저에서 `http://localhost:5173` 접속 후 회원가입하면 바로 사용할 수 있습니다.

### 휴대폰에서 접속하기 (같은 Wi-Fi 필요)

1. PC와 휴대폰이 같은 Wi-Fi에 연결되어 있어야 합니다.
2. `npm run dev`(클라이언트) 실행 시 터미널에 뜨는 `Network: http://<PC의 IP>:5173` 주소를
   휴대폰 브라우저에 입력합니다.
3. PC에서 만든 계정으로 로그인하면 저장한 매물이 그대로 보입니다.

클라이언트는 접속한 주소의 호스트를 그대로 써서 API 서버(4001번 포트)를 찾으므로,
`VITE_API_URL`을 따로 설정하지 않아도 PC/휴대폰 모두 자동으로 맞는 주소를 씁니다.

> 집 밖에서 모바일 데이터로 쓰거나 PC를 꺼도 계속 쓰려면 서버를 실제 호스팅
> (Railway, Render 등)에 올려야 합니다. 지금은 로컬 개발 환경 기준입니다.

## 데이터 저장

- **서버**: Express + Prisma(SQLite), `server/prisma/dev.db`에 매물 데이터를 저장.
- **사진**: `server/uploads/`에 파일로 저장, DB에는 경로만 기록.
- **인증**: 이메일/비밀번호 + JWT. 토큰은 클라이언트 localStorage에 보관.

## 목업과 달라진 점

- **거래유형**: 매매를 빼고 **전세 / 월세**만 남겼습니다.
- **매물 등록 방식**: 목업은 "링크 붙여넣기 / 캡처 이미지 자동인식"을 흉내낸 데모였지만,
  실제로는 부동산 사이트 스크래핑이나 이미지 OCR 없이는 자동 추출이 동작하지 않습니다.
  대신 **사진 업로드(최대 8장) + 직접 입력 폼**을 하나로 합쳐서, 사진을 참고자료로 첨부하면서
  정보는 직접 입력하는 방식으로 만들었습니다.
- **방문 평가 점수**: 목업은 항목별 점수가 고정된 더미 데이터였는데, 실제 앱에서는
  채광/방음/수압/교통/주변환경 5개 항목을 별점으로 직접 매기고 평균을 "내 점수"로 씁니다.
- 매물 **수정 / 삭제** 기능을 추가했습니다.
- 주소 옆에 네이버 지도로 바로 연결되는 링크, 중개사 연락처에 전화 걸기 버튼을 추가했습니다.
- **로그인/회원가입**을 추가해 여러 기기 간 동기화를 지원합니다.

## 폴더 구조

```
src/               클라이언트 (React + Vite + TS + Tailwind)
  pages/           목록 / 상세 / 등록·수정 폼 / 로그인·회원가입
  components/      카드, 배지, 별점, 사진 캐러셀 등 UI 조각
  store/           zustand 전역 상태 (매물 목록, 인증)
  api/             axios 클라이언트
  lib/             포맷팅, 점수 계산
  constants/       체크리스트 항목, 상태값 정의

server/            백엔드 (Express + Prisma/SQLite + JWT)
  src/routes/      auth (회원가입/로그인), listings (매물 CRUD)
  src/middleware/  JWT 인증 미들웨어
  prisma/          스키마 및 마이그레이션
  uploads/         업로드된 매물 사진
```
